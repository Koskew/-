# Журнал наблюдений

Мысли вслух на симуляторе. Каждая запись проходит один путь:

```
словами  →  точное условие  →  замер  →  правка или отказ
```

Ничего не попадает в индикатор, пока не пройдёт замер. Отрицательный
результат записывается так же, как положительный — три сильные на вид
связи уже умерли при проверке, и это сэкономило время.

**Статусы:** `новое` · `сформулировано` · `меряется` · `подтвердилось` ·
`не подтвердилось` · `внедрено`

## Открытые вопросы, перенесённые сюда

| # | вопрос | статус | что известно |
|---|---|---|---|
| О1 | Правило рисования боковика | `не подтвердилось` | Три размеченные вручную коробки дали три разных набора границ. Правило «N колен, размах ≤ K медиан» ловит все три только при покрытии 63–78% времени — бесполезно. КПД хода (размах / путь) лучше: при N=6 и КПД ≤ 0.30 покрытие 27%, но порог подогнан на одну коробку. Нужны ещё размеченные примеры. |
| О2 | Новые шаблоны триггерной свечи | `новое` | Текущие 40 форм перенесены из Тренажёра. Блок в коде помечен как заменяемый: меняются только три массива долей. Нужны формы — долями, словами или скриншотами. |
| О3 | Счёты глубиной ноль | `новое` | Из 464 счётов 100 имеют глубину 0 — одно колено, которое никуда не пошло. В боковой каше стрелка ↑↓ дёргается на соседних подписях. |
| О4 | Восходящий и нисходящий боковик в волнах | `новое` | Жду размеченный пример. |
| О5 | Смерть коробки коленами внутри | `новое` | Правило не сформулировано. |
| О6 | Пятиминутка длиннее 3.5 месяцев | `новое` | Нужна для проверки правила входа вне выборки. |
| О7 | Уровни как магниты | `новое` | Метки в двух ролях: структурный элемент и уровень, с которым цена дальше взаимодействует. Вторая роль ни разу не измерялась. |

## Решения, которые переспрашивать не нужно

Записаны в `ТРЕНД-ПРАВИЛА.md`, части 5 и 6.

* Пунктир ПЕРЕХОДА задним числом не переписывается.
* Направление счёта берётся по стороне нуля — 464 из 464.
* «Разворотный» и «продолжение» вместо жёсткой проверки правила.
* Запас — это оставшийся ход, а не порог прокола.
* Пауза после смерти — две метки, правило рабочее.
* Ступень «против тренда» в каскаде считает голоса и обгоняет честный
  тренд, потому что она быстрая. Заменять не надо.
* Мутность, число встречных 2/2 и глубина счёта не предсказывают ничего:
  все три связи оказались тавтологией и исчезли при нормировке.

## Записи

Формат новой записи:

```
### Н1 · дата · заголовок
**Словами:** как заметил.
**Условие:** точная формулировка, пригодная для проверки на баре.
**Замер:** что показали данные.
**Итог:** внедрено / отклонено / ждёт данных.
```
