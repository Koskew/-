## Зачем отдельный файл, а не только метка git

Чтобы сверка не требовала команд git: `research/sverka.py` принимает два
файла и сравнивает УСЛОВИЯ ПОКАЗА каждого рисующего вызова.

    python3 research/sverka.py indicator/ЭТАЛОН_v2.3.pine indicator/metki_prosto_v2.pine

Это и есть проверка по правилу 4 — «перед тем как отдать новую версию,
сверить с предыдущей и выписать, что исчезло». Теперь сверять есть с чем
без раскопок в истории.
